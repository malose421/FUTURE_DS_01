# 📊 Marketing Funnel & Conversion Analysis

## 📌 Project Overview

This project analyzes marketing campaign performance using customer data to understand conversion behavior and improve decision-making.

## 🎯 Objectives

* Analyze customer conversion patterns
* Identify drop-off points in the funnel
* Evaluate campaign effectiveness
* Provide business recommendations

## 🛠 Tools Used

* Power BI
* Data Analysis Techniques
* Business Intelligence

## 📊 Key Analysis Performed

* Conversion Rate Analysis
* Funnel Analysis (Total → Engaged → Converted)
* Campaign Performance Analysis
* Conversion by Job Role

## 📈 Key Insights

* A large number of customers were contacted, but only a small percentage converted
* Engagement (based on call duration) plays a key role in conversion
* Conversion rates vary across job categories
* Excessive campaign contacts reduce effectiveness

## 💡 Recommendations

* Focus on high-converting customer segments
* Improve engagement strategies during initial contact
* Reduce excessive follow-ups
* Optimize campaign targeting
